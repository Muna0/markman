What it does

Four IP analysis tools.
Two live API connections.

Markman is a Claude Code plugin that gives you structured IP analysis skills backed by real-time patent and trademark data from the USPTO and WIPO. It includes a configurable playbook for your firm's risk thresholds, deadline rules, and drafting preferences.

  • ✓Skills fire automatically when you discuss IP matters
  • ✓Slash commands for on-demand analysis (/review-claims, /tm-clearance, /fto-analysis)
  • ✓MCP servers handle rate limiting, retries, and data normalization
  • ✓Playbook is fully editable — match your firm's standards

Install

Up and running in 5 minutes.

Requires Node.js 18+ and Claude Code. API keys from USPTO and WIPO are free.

01

Get the tools

Install Node.js 18+ and Claude Code. Get free API keys from data.uspto.gov and wipo.int/case.

02

Install the plugin

Run claude plugin install markman in your terminal. Configure your API keys.

03

Start analyzing

Open Claude Code and type /review-claims with any patent number. Or just describe an IP matter.

terminal
# Clone and install $ git clone https://github.com/markman-ip/markman.git $ cd markman && npm install added 91 packages in 3s # Configure API keys $ echo "USPTO_API_KEY=your_key" > .env $ echo "WIPO_API_KEY=your_key" >> .env # Install plugin $ claude plugin install ./ ✓ Plugin "markman" installed successfully 4 skills · 3 commands · 2 MCP servers # Verify $ claude doctor ✓ All checks passed
